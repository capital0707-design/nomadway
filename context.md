# NomadWay — Проект трансферных услуг в Кыргызстане

## 📋 Общая информация
Веб-приложение для бронирования трансферных услуг в Кыргызстане. Проект на стадии завершения, осталось подключить оплату и исправить несколько багов.

## 🛠 Стек технологий

### Frontend
- **Сборщик:** Vite (SPA - Single Page Application)
- **Язык:** TypeScript
- **UI библиотека:** React
- **Стилизация:** Tailwind CSS
- **Конфигурация:** 
  - `vite.config.ts` - настройка сборщика
  - `tailwind.config.js` - конфигурация Tailwind
  - `postcss.config.js` - PostCSS настройки
  - `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json` - TypeScript конфиги

### Backend
- **Платформа:** Supabase
- **База данных:** PostgreSQL
- **Функции:** 
  - Аутентификация пользователей
  - Realtime API
  - Хранение данных
- **Папка:** `/supabase` в корне проекта
