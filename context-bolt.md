## 1. Стек и Архитектура
* **Frontend:** React + Vite + TypeScript (SPA).
* **Стили:** Tailwind CSS + PostCSS.
* **Бэкенд / База данных / Auth:** Supabase (PostgreSQL).
* **Ключевые файлы конфигурации:** `vite.config.ts`, `tsconfig.json`, `tailwind.config.js`, `.env`.
* **Структура папок:**
  - `/supabase` — миграции, конфигурация базы данных и локальные настройки Supabase.
  - `/src` — исходный код приложения (компоненты, страницы, логика).
  - `/dist` — папка готовой сборки проекта.
  - `/.bolt` — системные файлы конфигурации Bolt.new.
